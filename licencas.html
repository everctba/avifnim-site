AVIFnim is proprietary software, but it uses third-party components. Each keeps its own license, and nothing in the AVIFnim contract restricts the rights you have over them.

FFmpeg — GPL

AVIFnim runs FFmpeg as a separate program (child process, via command line), without linking the libraries to the application. The distributed binary is GPL and the corresponding source code is available below.

  • Windows: FFmpeg 7.1 (gyan.dev essentials) — source + build scripts.
  • Linux: FFmpeg n8.1 (BtbN/FFmpeg-Builds GPL) — build + source.
  • macOS: FFmpeg 6.1.1 (eugeneware/ffmpeg-static b6.1.1) — build + source.

Written offer (GPLv3): for 3 years from receipt, the corresponding source code can be requested at mayerdesigner@gmail.com. License text: GPLv3.
