AVIFnim user guide

AVIFnim converts image sequences and videos into animated AVIF (and also animated WebP/GIF). It ships in three forms that share the same conversion engine:

Desktop

Window with a UI: drag images, trim video, record the screen and export.

CLI + MCP

The avifnim command on your PATH and an MCP server for Claude, OpenCode, Cursor and other agents.

Choosing components in the installer

The installer shows a screen with two independent options:

OptionWhat it installsNeeds admin?
Desktop app GUI + Start Menu and Desktop shortcuts No
CLI + MCP The avifnim command on the user PATH, installed in <install folder>\resources\cli (next to the app) No

You can select both (recommended), the desktop only, or the CLI/MCP only.

PATH: the installer adds <install folder>\resources\cli to the user PATH (registry HKCU\Environment) — in other words, the CLI lives in the same folder you chose to install the app. Terminals that are already open do not see the change: close and reopen the terminal after installing.

Checking the installation

avifnim version
avifnim doctor

doctor shows the paths to ffmpeg.exe and avifenc.exe, the supported GPUs and whether the command is on the PATH.

1.1 Linux — deb and AppImage

Linux has no Setup.exe: there are two formats with different trade-offs.

.deb — full version (Desktop + CLI + MCP)

Installs to /opt/AVIFnim, creates the menu entry (.desktop) and puts the avifnim command on the PATH through /usr/bin/avifnim. 

sudo apt install ./avifnim_1.1.0_amd64.deb

# check
avifnim doctor
avifnim init

# uninstall (removes files, menu entry and the avifnim command)
sudo apt remove avifnim

Works on Ubuntu, Debian, Mint, Pop!_OS and derivatives (.deb installers).

AppImage — Desktop only

A single executable file, no installation and no PATH changes. In this build the AppImage does not include the CLI/MCP — it is the GUI only. 

chmod +x AVIFnim-1.1.0-x86_64.AppImage
./AVIFnim-1.1.0-x86_64.AppImage

To add it to the menu, use AppImageLauncher or create a .desktop file yourself. If you want the avifnim command, use the .deb.

Important difference: on Windows the installer asks where to install and edits the user PATH. On Linux the package manager does the installing: the .deb goes to /opt and uses /usr/bin (already on the PATH); the AppImage stays wherever you put it and registers nothing.

Building from source (Linux)

The Linux build must run on Linux (or WSL/container), because electron-builder uses native tools (fpm/dpkg). First, put the Linux binaries in src/main/utils/ffmpeg-bin/ffmpeg and src/main/utils/avifenc-bin/avifenc. 

npm run build:linux:deb        # full .deb (Desktop + CLI + MCP)
npm run build:linux:appimage   # AppImage (Desktop only)

1.2 macOS — .pkg installer

Two installers: Apple Silicon (arm64) and Intel (x64). The .pkg installs the app and the CLI/MCP at once.

Installation

The installer places:

  • /Applications/AVIFnim.app
  • /usr/local/bin/avifnim (CLI + MCP, already on the default PATH)

Open the .pkg and follow the installer. If macOS blocks it because it is unsigned:

  • right-click the .pkg → Open; or
  • run in Terminal:
sudo installer -pkg AVIFnim-1.1.0-arm64.pkg -target /

CLI + MCP

After installing, the command is already on the PATH:

avifnim doctor
avifnim init
avifnim mcp

If you installed via DMG/drag-and-drop, open About → CLI + MCP and click Install on PATH.

Remove

sudo rm -f /usr/local/bin/avifnim

Then drag AVIFnim from Applications to the Trash.

Intel Macs on Catalina 10.15.7: there is a separate AVIFnim-1.1.0-x64-catalina.pkg package, using Electron 32 (unsupported).

Signing: the test build uses an ad-hoc app signature and an unsigned .pkg. To distribute without the Gatekeeper warning, you need Developer ID Application + Developer ID Installer + notarization (Apple Developer Program).

2. Desktop app

Sequence to AVIF

Drag the images (PNG, JPG, WebP, GIF) or click Select files. When you pick a numbered frame (frame_0001.png), the app automatically detects the whole sequence in the same directory (same prefix, suffix and extension).

Video to AVIF

Load a video, set the range (start/end), the crop, the FPS and the scale. The preview uses a cached MP4 proxy — the final file is still animated AVIF.

You can also open an existing animated AVIF (Select video → .avif): the app extracts frames to the installation cache, applies trim/crop/scale and re-encodes while keeping transparency. Re-encoding is lossy → lossy (generation loss), so the app warns you the first time, with a “Don't show this again” option. For the best quality, always export again from the original material (PNG or video).

Record screen

Records the screen or a window and sends the result straight into the conversion flow.

When recording the entire screen with Camera follows the mouse, the framing already shows in the player: the preview displays the cropped area following the cursor before converting. The camera zoom (1.3×, 1.5×, 2× and 2.5×) updates the preview instantly; unchecking the option returns to manual crop. The camera does not apply to window recordings — full screen only.

Quality, speed and GPU

QualityCRF (AVIF)When to use
máximo (topo)15Maximum quality, larger file
levisio20Site hero, showcase
leve25Balance for the web
original30Default
medio35Background animations
qualidadeok45Smallest file, previews

With a compatible GPU the AVIF uses NVENC (NVIDIA), AMF (AMD) or QuickSync (Intel); if the encoder fails, the app automatically falls back to CPU (libaom-av1).

Transparency

PNG/WebP with an alpha channel use avifenc to build the AVIF alpha item. This path is limited to 2000 frames per conversion.

Help inside the app

Menu Help → User guide (or F1) opens this page. Help → About shows the version and project links.

3. CLI — the avifnim command

The CLI runs without opening a window and uses the same presets, encoders and binaries as the app.

Examples

# PNG sequence (folder)
avifnim convert "C:\project\render" --out "C:\project\public\img\hero.avif" --fps 24

# From any frame (numbering is detected automatically)
avifnim convert "C:\project\render\frame_0001.png" --out "C:\project\img\hero.avif"

# Video with trim, crop and 50% size
avifnim convert "C:\videos\loop.mp4" --out "C:\site\img\loop.avif" \
  --start 2 --end 5 --fps 24 --scale 0.5

# Recompress an animated AVIF (lossy -> lossy: prefer the original material)
avifnim convert "C:\site\img\hero.avif" --out "C:\site\img\hero-min.avif" \
  --scale 0.75 --quality medio

# Animated GIF (useful for previews)
avifnim convert "C:\project\render" --format gif --out "C:\project\preview.gif"

# Inspect before converting
avifnim detect "C:\project\render" --json

4. MCP — server for AI agents

MCP (Model Context Protocol) lets an agent call the conversion as a tool, without you typing commands. The server speaks JSON-RPC over stdio: no ports, no network.

1) Register the server

In your project root, create .mcp.json (Claude Code, Cursor, Windsurf, Codex):

{
  "mcpServers": {
    "avifnim": {
      "command": "avifnim",
      "args": ["mcp"]
    }
  }
}

In Claude Desktop, the same block goes in %APPDATA%\Claude\claude_desktop_config.json (Windows) or ~/.config/Claude/claude_desktop_config.json (Linux).

In OpenCode (opencode.json or opencode.jsonc):

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "avifnim": {
      "type": "local",
      "command": ["avifnim", "mcp"],
      "enabled": true
    }
  }
}
If the client cannot find avifnim, use the absolute path to the executable (avifnim doctor shows it) or run avifnim init, which prints the config with the resolved path.

2) Instructions for the agent

Run avifnim init with your project paths. It prints a block ready to paste into AGENTS.md, CLAUDE.md or rules.md: 

avifnim init --input "C:\project\render" --output "C:\project\public\img\hero.avif" --type sequence

# or write it straight into AGENTS.md (and CLAUDE.md, if it exists)
avifnim init --write --input "C:\project\render" --type sequence

# video with specific fps and quality
avifnim init --input "C:\videos\loop.mp4" --type video --fps 24 --quality levisio

The generated block contains:

  • the input type (image sequence or video);
  • the input path the agent should use;
  • the default output path;
  • recommended FPS, quality, speed and scale;
  • the rules (never overwrite, inspect first, report the final path).
The block sits between <!-- AVIFNIM-MCP:START --> and <!-- AVIFNIM-MCP:END -->. Running --write again updates the block without duplicating it (run it as many times as you want).
FPS: if you do not pass fps, the video keeps its source FPS (capped at 60) and image sequences use 30. Pass fps to lower it (e.g. 24) and reduce the file size.

4) Example conversation

You: "Convert the video video.mp4 into an animated AVIF for the site hero."

Agent: calls avif_from_video (with inputPath = the video) and answers: "Done: public/img/hero.avif, 90 frames, 1920×1080, 1.2 MB."

Do not extract a frame from the video. If the agent grabs an image (ffmpeg -ss 1.2 -i video.mp4 frame.png) and calls avif_from_sequence, the AVIF will have a single frame and stay frozen. For video, always use avif_from_video with the video path. The sequence tool rejects a single image by default (it only accepts it with allowSingleFrame: true).

Testing the server without AI

# The server reads JSON-RPC per line on stdin and replies on stdout
echo {"jsonrpc":"2.0","id":1,"method":"tools/list"} | avifnim mcp

5. Troubleshooting

avifnim is not recognized

  • Close and reopen the terminal (the PATH is only read when it starts).
  • Check that <install folder>\resources\cli\avifnim.exe exists.
  • Run avifnim doctor; if the PATH is wrong, reinstall with "CLI + MCP" checked.

ffmpeg / avifenc not found

Run avifnim doctor. If they are missing, the installation is incomplete: reinstall. To use your own binaries, set AVIFNIM_FFMPEG and/or AVIFNIM_AVIFENC.

GPU not used

AVIFnim tests the hardware encoder before using it. If it fails, it falls back to CPU automatically. Force it with --encoder cpu (or gpu to require a GPU in MCP clients).

On Linux, FFmpeg must be built with NVENC (--enable-nvenc / --enable-ffnvcodec). The official installer already includes it; if you replace the binary, use a build with av1_nvenc (for example, BtbN/FFmpeg-Builds GPL).

GPU is faster. GPU: smaller file is enabled by default and uses periodic keyframes, producing much smaller files. Uncheck it for maximum compatibility (every frame as a keyframe), or use the CPU engine for the final render — CPU produces the smallest files, at the cost of time.

The AVIF came out frozen (only the first frame)

It is almost always because the agent extracted one frame from the video and converted it as a sequence. Convert the video directly with avif_from_video (MCP) or avifnim convert "video.mp4" --out "out.avif" (CLI). If you really want a static AVIF of a single image, use allowSingleFrame: true in MCP.

The AVIF is heavy or "stuttering" during playback

Animated AVIF is **all-intra**: every frame is a complete AV1 frame, with no inter-frame prediction. Above 1920 px on the longest side, the browser decoder may not keep up with the FPS and the player drops frames (stutter) — and the file becomes larger than the original video. The CLI/MCP warns when this happens.

Fix: --max-width 1920 (or 1280 for a hero), --fps 30 or lower and, if needed, medio/qualidadeok quality.

Transparency in a long sequence

The alpha path through avifenc accepts up to 2000 frames. Above that, shorten the sequence, use --scale 0.5 to reduce the cost, or convert it in parts.

The output was not overwritten

That is intentional. Use --force to overwrite or delete the file first.

The MCP client does not start the server

  • Use the absolute path to the executable in command.
  • Make sure avifnim mcp works on its own in the terminal (it just sits there waiting for JSON, that is normal).
  • Restart the client after editing the config JSON.

Spaces and accents in paths

Always quote paths in the CLI. The installer and the CLI support accents (UTF-8), but older third-party tools may not.

7. FAQ

Do I need the desktop app to use the CLI?

No. The CLI/MCP uses the bundled binaries and runs headless. But the installer always copies the app files (it is a single package); without the desktop component you simply do not get shortcuts.

What happens if I uninstall?

The uninstaller removes the shortcuts, the user PATH entry and the resources\cli folder (if it still exists).

Can I use it in CI/CD?

Yes: avifnim convert ... --json returns JSON and stable exit codes.

Where are the presets?

Same as the app: máximo (accepts topo/max), levisio, leve, medio, qualidadeok, original, plus a numeric CRF (0–63) in the CLI.
