Tecnologia

Velocidade de GPU

O AVIFnim usa o encoder AV1 por hardware quando disponível. Se a GPU não suportar AV1, ele cai para a CPU automaticamente, sem configuração.

NVENC · NVIDIA

Encode AV1 por hardware nas GPUs NVIDIA compatíveis (RTX 40 em diante).

AMF · AMD

Encoder AV1 por hardware nas Radeon com AMF compatível (RX 7000 em diante).

QuickSync · Intel

Aceleração AV1 por hardware em Intel Arc e iGPUs com QuickSync compatível.

CPU · libaom

Fallback automático quando não há GPU AV1. Usa todos os núcleos e funciona em qualquer máquina — mais lento que a GPU, mas sem configuração.

AV1 é livre de royalties (AOMedia). O motor usa FFmpeg (GPL), libavif (BSD-2-Clause) e Electron (MIT). Licenças de terceiros.

Para agentes de IA

Seu agente converte e já usa no HTML

O AVIFnim instala um CLI e um servidor MCP no PATH. O agente AI usa a sequência de PNGs na conversão do AVIF e insere no seu site, sem precisar abrir o app.

  1. 1 AVIFnim renderiza a sequência de PNGs.
  2. 2 O MCP converte e sugere o destino.
  3. 3 O agente usa o AVIF no HTML.
Informe as Tools ao agente
  • Diz ao agente: “existe um servidor chamado avifnim, execute avifnim mcp”
Configura o projeto para o agente 
avifnim init --write \
  --input "C:\projeto\render" \
  --output "C:\projeto\public\img\hero.avif" \
  --type sequence
Registra o servidor MCP (.mcp.json) 
{
  "mcpServers": {
    "avifnim": {
      "command": "avifnim",
      "args": ["mcp"]
    }
  }
}

FAQ

Perguntas frequentes

O AVIFnim é assinatura?

Não. É uma licença única de US$ 9,90, paga uma vez, sem renovação. A Microsoft Store cobra na moeda local; no Gumroad, em USD. Você tem licença permanente para a versão adquirida; correções da linha 1.x são publicadas quando disponíveis — sem mensalidade.

Preciso de placa de vídeo?

Não. Com GPU compatível, o encode usa NVENC (NVIDIA), AMF (AMD) ou QuickSync (Intel); sem GPU, cai automaticamente para CPU (libaom). O foco da GPU é velocidade; o tamanho depende do formato, da qualidade e do modo “GPU: arquivo menor”.

Meus arquivos são enviados para algum lugar?

Não. Tudo roda localmente — app, CLI e MCP. Sem upload, sem conta e sem telemetria. Depois de instalar, você pode usar offline.

Só quero visualizar AVIF. Preciso comprar?

Não. O AVIFnim Viewer é grátis e open source (MIT) para abrir AVIF, WebP, GIF e PPM/PNM. O AVIFnim pago é para criar e converter sequências, vídeos e gravações de tela. Comece pelo Viewer; se precisar criar, a licença é única.

O que está incluído na licença?

App desktop + CLI avifnim + servidor MCP, para Windows, macOS e Linux. Licença para 1 pessoa e 1 computador fora da Store; uso comercial permitido. Na Microsoft Store, valem os limites de dispositivo da conta.

Consigo converter vídeo e gravação de tela?

Sim: MP4, MKV, MOV, WEBM e AVI, com trim e crop; gravação de tela com câmera que segue o cursor; exporta AVIF, WebP ou GIF. Para vídeos longos, o foco é loops e trechos — teste o seu caso.

O código é aberto?

O AVIFnim Viewer é open source (MIT). O AVIFnim conversor é proprietário, distribuído como binário. As licenças de terceiros (FFmpeg GPL, libavif BSD, Electron MIT) estão em Ajuda → Licenças e no site.

Funciona com Claude, OpenCode ou Cursor?

Sim. O instalador inclui o CLI e um servidor MCP. Rode avifnim init no projeto e cole o bloco no AGENTS.md/CLAUDE.md; o agente passa a converter e devolver o caminho final.
