Guia de uso do AVIFnim

O AVIFnim converte sequências de imagens e vídeos em AVIF animado (e também WebP/GIF animado). Ele existe de três formas que compartilham o mesmo motor de conversão:

Desktop

Janela com interface: arrastar imagens, cortar vídeo, gravar tela e exportar.

CLI + MCP

Comando avifnim no PATH e servidor MCP para Claude, OpenCode, Cursor e outros agentes.

Escolhendo os componentes no instalador

O instalador mostra uma tela com duas opções independentes:

OpçãoO que instalaPrecisa de admin?
Aplicativo desktop Interface gráfica + atalhos no Menu Iniciar e na Área de Trabalho Não
CLI + MCP Comando avifnim no PATH do usuário, instalado em <pasta de instalação>\resources\cli (junto com o app) Não

Você pode marcar as duas (recomendado), só o desktop ou só o CLI/MCP.

PATH: o instalador adiciona <pasta de instalação>\resources\cli ao PATH do usuário (registro HKCU\Environment) — ou seja, o CLI fica na mesma pasta que você escolheu para instalar o app. Terminais já abertos não enxergam a mudança: feche e abra o terminal depois de instalar.

Verificando a instalação

avifnim version
avifnim doctor

O doctor mostra os caminhos do ffmpeg.exe e do avifenc.exe, as GPUs suportadas e se o comando está no PATH.

1.1 Linux — deb e AppImage

No Linux não existe um Setup.exe: são dois formatos com propostas diferentes.

.deb — versão completa (Desktop + CLI + MCP)

Instala em /opt/AVIFnim, cria o atalho no menu (.desktop) e coloca o comando avifnim no PATH via /usr/bin/avifnim. 

sudo apt install ./avifnim_1.1.0_amd64.deb

# conferir
avifnim doctor
avifnim init

# desinstalar (remove arquivos, atalho e o comando avifnim)
sudo apt remove avifnim

Compatível com Ubuntu, Debian, Mint, Pop!_OS e derivados (instaladores .deb).

AppImage — apenas o Desktop

Um único arquivo executável, sem instalação e sem mexer no PATH. Nesta versão o AppImage não inclui o CLI/MCP — é só a interface gráfica. 

chmod +x AVIFnim-1.1.0-x86_64.AppImage
./AVIFnim-1.1.0-x86_64.AppImage

Para integrar ao menu, use o AppImageLauncher ou crie um .desktop manualmente. Para ter o comando avifnim, use o .deb.

Diferença importante: no Windows o instalador pergunta onde instalar e mexe no PATH do usuário. No Linux quem instala é o gerenciador de pacotes: o .deb vai para /opt e usa /usr/bin (já no PATH); o AppImage fica onde você quiser e não registra nada.

Compilando a partir do código (Linux)

O build Linux precisa rodar no Linux (ou WSL/container), porque o electron-builder usa ferramentas nativas (fpm/dpkg). Antes, coloque os binários Linux em src/main/utils/ffmpeg-bin/ffmpeg e src/main/utils/avifenc-bin/avifenc. 

npm run build:linux:deb        # .deb completo (Desktop + CLI + MCP)
npm run build:linux:appimage   # AppImage (somente Desktop)

1.2 macOS — instalador .pkg

Dois instaladores: Apple Silicon (arm64) e Intel (x64). O .pkg instala o app e o CLI/MCP de uma vez.

Instalação

O instalador coloca:

  • /Applications/AVIFnim.app
  • /usr/local/bin/avifnim (CLI + MCP, já no PATH padrão)

Abra o .pkg e siga o instalador. Se o macOS bloquear por não ser assinado:

  • clique com o botão direito no .pkg → Abrir; ou
  • rode no Terminal:
sudo installer -pkg AVIFnim-1.1.0-arm64.pkg -target /

CLI + MCP

Depois de instalar, o comando já está no PATH:

avifnim doctor
avifnim init
avifnim mcp

Se você instalou por DMG/arrastar-e-soltar, abra Sobre → CLI + MCP e clique em Instalar no PATH.

Remover

sudo rm -f /usr/local/bin/avifnim

Depois arraste o AVIFnim de Applications para o Lixo.

Macs Intel no Catalina 10.15.7: existe um pacote separado AVIFnim-1.1.0-x64-catalina.pkg, com Electron 32 (sem suporte oficial).

Assinatura: o build de teste usa assinatura ad-hoc e o .pkg não é assinado. Para distribuir sem o aviso do Gatekeeper, é preciso Developer ID Application + Developer ID Installer + notarização (Apple Developer Program).

2. Aplicativo desktop

Sequence to AVIF

Arraste as imagens (PNG, JPG, WebP, GIF) ou clique em Selecionar arquivos. Ao escolher um frame numerado (frame_0001.png), o app detecta automaticamente a sequência inteira no mesmo diretório (mesmo prefixo, sufixo e extensão).

Video to AVIF

Carregue um vídeo, defina o trecho (início/fim), o recorte, o FPS e a escala. O preview usa um proxy MP4 gerado em cache — o arquivo final continua sendo AVIF animado.

Também é possível abrir um AVIF animado existente (Selecionar vídeo → .avif): o app extrai os frames para o cache da instalação, aplica trim/crop/escala e recodifica preservando a transparência. Como a recodificação é lossy → lossy (perda de geração), o app mostra um aviso na primeira vez, com a opção “Não mostrar novamente”. Para a melhor qualidade, prefira reexportar do material original (PNG ou vídeo).

Gravar tela

Grava a tela ou uma janela e leva o resultado direto para o fluxo de conversão.

Ao gravar a tela inteira com Câmera segue o mouse, o enquadramento já aparece no player: a prévia mostra a área recortada seguindo o cursor antes de converter. O zoom da câmera (1.3×, 1.5×, 2× e 2.5×) atualiza a prévia na hora; desmarcar a opção volta ao crop manual. A câmera não se aplica a gravação de janela — só tela inteira.

Qualidade, velocidade e GPU

QualidadeCRF (AVIF)Quando usar
máximo (topo)15Máxima qualidade, arquivo maior
levisio20Hero de site, vitrine
leve25Equilíbrio para web
original30Padrão
medio35Animações de fundo
qualidadeok45Menor arquivo, previews

Com GPU compatível o AVIF usa NVENC (NVIDIA), AMF (AMD) ou QuickSync (Intel); se o encoder falhar, o app cai automaticamente para CPU (libaom-av1).

Transparência

PNG/WebP com canal alpha usam o avifenc para gerar o item de alpha do AVIF. Esse caminho tem limite de 2000 frames por conversão.

Ajuda dentro do app

Menu Ajuda → Guia de uso (ou F1) abre esta página. Ajuda → Sobre mostra a versão e os links do projeto.

3. CLI — comando avifnim

O CLI roda sem abrir janela e usa os mesmos presets, encoders e binários do app.

Comandos

avifnim detect <entrada>Inspeciona tipo, frames, lacunas, dimensões e transparência

Exemplos

# Sequência de PNGs (pasta)
avifnim convert "C:\projeto\render" --out "C:\projeto\public\img\hero.avif" --fps 24

# A partir de um frame qualquer (detecta a numeração sozinho)
avifnim convert "C:\projeto\render\frame_0001.png" --out "C:\projeto\img\hero.avif"

# Vídeo com trim, recorte e 50% do tamanho
avifnim convert "C:\videos\loop.mp4" --out "C:\site\img\loop.avif" \
  --start 2 --end 5 --fps 24 --scale 0.5

# Recompactar um AVIF animado (lossy -> lossy: prefira o material original)
avifnim convert "C:\site\img\hero.avif" --out "C:\site\img\hero-min.avif" \
  --scale 0.75 --quality medio

# GIF animado (útil para previews)
avifnim convert "C:\projeto\render" --format gif --out "C:\projeto\preview.gif"

# Inspecionar antes de converter
avifnim detect "C:\projeto\render" --json

4. MCP — servidor para agentes de IA

O MCP (Model Context Protocol) permite que um agente chame a conversão como ferramenta, sem você digitar comandos. O servidor fala JSON-RPC em stdio: nada de portas ou rede.

1) Registrar o servidor

Na raiz do projeto, crie .mcp.json (Claude Code, Cursor, Windsurf, Codex):

{
  "mcpServers": {
    "avifnim": {
      "command": "avifnim",
      "args": ["mcp"]
    }
  }
}

No Claude Desktop, o mesmo bloco vai em %APPDATA%\Claude\claude_desktop_config.json (Windows) ou ~/.config/Claude/claude_desktop_config.json (Linux).

No OpenCode (opencode.json ou opencode.jsonc):

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "avifnim": {
      "type": "local",
      "command": ["avifnim", "mcp"],
      "enabled": true
    }
  }
}
Se o cliente não encontrar avifnim, use o caminho absoluto do executável (avifnim doctor mostra) ou rode avifnim init, que já imprime a config com o caminho resolvido.

2) Instruções para o agente

Rode avifnim init com os caminhos do seu projeto. Ele imprime um bloco pronto para colar em AGENTS.md, CLAUDE.md ou rules.md: 

avifnim init --input "C:\projeto\render" --output "C:\projeto\public\img\hero.avif" --type sequence

# ou grave direto no AGENTS.md (e no CLAUDE.md, se existir)
avifnim init --write --input "C:\projeto\render" --type sequence

# vídeo com fps e qualidade específicos
avifnim init --input "C:\videos\loop.mp4" --type video --fps 24 --quality levisio

O bloco gerado contém:

  • o tipo da entrada (sequência de imagens ou vídeo);
  • o caminho de entrada que o agente deve usar;
  • o caminho de saída padrão;
  • FPS, qualidade, velocidade e escala recomendados;
  • as regras (nunca sobrescrever, inspecionar antes, reportar o caminho final).
O bloco fica entre <!-- AVIFNIM-MCP:START --> e <!-- AVIFNIM-MCP:END -->. Rodar --write de novo atualiza o bloco sem duplicar (dá para rodar quantas vezes quiser).
FPS: se você não informar fps, o vídeo mantém o FPS de origem (limitado a 60) e sequências de imagens usam 30. Informe fps para reduzir (ex.: 24) e diminuir o tamanho do arquivo.

3) Ferramentas expostas

4) Exemplo de conversa

Você: "Converte o vídeo video.mp4 num AVIF animado para o hero do site."

Agente: chama avif_from_video (com inputPath = o vídeo) e responde: "Pronto: public/img/hero.avif, 90 frames, 1920×1080, 1.2 MB."

Não extraia um frame do vídeo. Se o agente tirar uma imagem (ffmpeg -ss 1.2 -i video.mp4 frame.png) e chamar avif_from_sequence, o AVIF terá um único frame e ficará parado. Para vídeo, use sempre avif_from_video com o caminho do vídeo. A tool de sequência recusa 1 imagem por padrão (só aceita com allowSingleFrame: true).

Testando o servidor sem IA

# O servidor lê JSON-RPC por linha no stdin e responde no stdout
echo {"jsonrpc":"2.0","id":1,"method":"tools/list"} | avifnim mcp

5. Solução de problemas

avifnim não é reconhecido

  • Feche e abra o terminal (o PATH só é lido na abertura).
  • Confira se <pasta de instalação>\resources\cli\avifnim.exe existe.
  • Rode avifnim doctor; se o PATH estiver errado, reinstale marcando "CLI + MCP".

ffmpeg / avifenc não encontrado

Rode avifnim doctor. Se estiver ausente, a instalação está incompleta: reinstale. Para usar binários próprios, defina AVIFNIM_FFMPEG e/ou AVIFNIM_AVIFENC.

GPU não usada

O AVIFnim testa o encoder de hardware antes de usar. Se falhar, cai para CPU automaticamente. Force com --encoder cpu (ou gpu para exigir GPU em clientes MCP).

No Linux, o FFmpeg precisa ter sido compilado com NVENC (--enable-nvenc / --enable-ffnvcodec). O instalador oficial já inclui; se trocar o binário, use um build com av1_nvenc (por exemplo, BtbN/FFmpeg-Builds GPL).

A GPU é mais rápida. A opção GPU: arquivo menor vem ativada por padrão e usa frames-chave periódicos, gerando arquivos bem menores. Desmarque para compatibilidade máxima (keyframe em todos os quadros) ou use o motor CPU no render final — a CPU gera os menores arquivos, ao custo de tempo.

O AVIF saiu parado (só o primeiro frame)

Quase sempre é porque o agente extraiu um frame do vídeo e converteu como sequência. Converta o vídeo direto com avif_from_video (MCP) ou avifnim convert "video.mp4" --out "saida.avif" (CLI). Se você realmente quer um AVIF estático de uma imagem, use allowSingleFrame: true no MCP.

O AVIF ficou pesado ou "travando" ao reproduzir

AVIF animado é **all-intra**: cada frame é um AV1 completo, sem predição entre frames. Acima de 1920 px no maior lado, o decoder do navegador pode não acompanhar o FPS e o player descarta frames (sensação de travamento) — além do arquivo ficar maior que o vídeo original. O CLI/MCP avisa quando isso acontece.

Solução: --max-width 1920 (ou 1280 para hero), --fps 30 ou menos e, se necessário, qualidade medio/qualidadeok.

Transparência em sequência grande

O caminho com alpha via avifenc aceita até 2000 frames. Acima disso, reduza a sequência, use --scale 0.5 para diminuir o custo ou converta em partes.

Saída não foi sobrescrita

É proposital. Use --force para sobrescrever ou apague o arquivo antes.

Cliente MCP não inicia o servidor

  • Use o caminho absoluto do executável no command.
  • Garanta que avifnim mcp funciona isolado no terminal (ele fica "parado" esperando JSON, é normal).
  • Reinicie o cliente depois de editar o JSON de configuração.

Espaços e acentos nos caminhos

Sempre coloque os caminhos entre aspas no CLI. O instalador e o CLI suportam acentos (UTF-8), mas ferramentas antigas de terceiros podem não suportar.

7. Perguntas frequentes

Preciso do app desktop para usar o CLI?

Não. O CLI/MCP usa os binários embutidos e roda headless. Mas o instalador sempre copia os arquivos do app (é um pacote único); sem o componente desktop você simplesmente não recebe atalhos.

O que acontece se eu desinstalar?

O desinstalador remove os atalhos, a entrada do PATH do usuário e a pasta resources\cli (se ela ainda existir).

Posso usar em CI/CD?

Sim: avifnim convert ... --json devolve JSON e códigos de saída estáveis.

Onde ficam os presets?

Os mesmos do app: máximo (aceita topo/max), levisio, leve, medio, qualidadeok, original, além de CRF numérico (0–63) no CLI.
