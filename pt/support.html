Precisa de ajuda com o AVIFnim Viewer? O app é gratuito e open source (MIT); o suporte é feito em melhor esforço, sem SLA.

English summary

Need help? Open a GitHub issue or email mayerdesigner@gmail.com. Include the app version, your OS, the file format, the steps and a screenshot if possible. AVIFnim Viewer is free and MIT; support is best effort, with no SLA. The app collects no telemetry and does not upload your files.

1. Canais de suporte

  • GitHub Issues (preferido): github.com/everctba/AVIFnim-Viewer/issues — fica público e ajuda outras pessoas com o mesmo problema.
  • E-mail: mayerdesigner@gmail.com — para assuntos que não devem ser públicos (por exemplo, dados sensíveis no relato).
  • Microsoft Store: para problemas de instalação, atualização ou conta, use o suporte da própria Store. O app é gratuito.

2. Antes de pedir ajuda

  • Confirme se você está na versão mais recente (GitHub Releases ou Microsoft Store).
  • Tente abrir outro arquivo do mesmo formato para ver se o problema é do arquivo.
  • No Windows, reinicie o app depois de instalar/atualizar.
  • No macOS, se o app não abrir, veja a seção sobre o aviso de desenvolvedor não verificado.
  • No Linux, confirme a distro e a versão do WebKitGTK.

3. Perguntas frequentes

O AVIFnim Viewer é grátis?

Sim. É gratuito, open source e licenciado sob MIT. Não existe versão “premium” do visualizador.

Quais formatos ele abre?

AVIF (still e animado), WebP (still e animado), GIF, PPM/PNM (P1–P6), PNG e JPG individuais, e sequências numeradas de PNG/JPG.

Quais sistemas são suportados?

Windows 10/11 x64 (instalador NSIS ou Microsoft Store), macOS 13+ (Intel e Apple Silicon) e Linux x64 (Ubuntu 24.04+ / Linux Mint, com WebKitGTK 4.1).

Não consigo abrir uma imagem. O que fazer?

Confirme se o arquivo abre em outro programa e se a extensão corresponde ao conteúdo. Se continuar, envie o formato, a versão do app, o sistema e o passo a passo. Se puder, anexe uma captura de tela.

O macOS avisa que o desenvolvedor não pode ser verificado.

O app ainda não é assinado/notarizado pela Apple. Na primeira abertura, clique com o botão direito no app → Abrir → Abrir. Se necessário, use Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.

Ele toca AVIF animado no Linux?

Sim. Quando o WebKitGTK do sistema não decodifica AVIF, o app usa um decodificador nativo em Rust como fallback. Se falhar, informe a distro e a versão do WebKitGTK.

Existe versão portátil no Windows?

A versão portátil está planejada (“em breve”). Hoje o instalador NSIS é o formato disponível; ele permite desinstalar pelos aplicativos do Windows.

Onde ficam as configurações?

Na pasta de dados do app: %APPDATA%\com.avifnim.viewer no Windows, ~/Library/Application Support/com.avifnim.viewer no macOS e ~/.config/com.avifnim.viewer no Linux. Nada é sincronizado.

Meus arquivos são enviados para algum lugar?

Não. Tudo é processado localmente. O app não tem telemetria, contas ou nuvem. Veja a Política de Privacidade.

Como desinstalar?

No Windows, use Configurações → Aplicativos → Aplicativos instalados. No macOS, arraste o app para o Lixo. No Linux, remova pelo gerenciador de pacotes (.deb). As configurações locais podem ser apagadas manualmente.

Como reportar um bug?

Abra uma issue no GitHub ou envie e-mail com: versão do app, sistema, formato do arquivo, passos para reproduzir e, se possível, uma captura de tela. Não envie arquivos confidenciais sem necessidade.

4. Problemas conhecidos

  • macOS: o app ainda não é assinado/notarizado; use “Abrir” no menu de contexto na primeira execução.
  • Windows: o instalador NSIS pode acionar o SmartScreen por não ter assinatura de código; use “Mais informações → Executar assim mesmo”. Na Microsoft Store, esse aviso não aparece.
  • Linux: o AVIF depende do WebKitGTK 4.1; em distros mais antigas, o fallback em Rust cobre a decodificação.
  • Versão portátil: ainda não publicada; use o instalador.

5. Tempo de resposta

O Viewer é mantido em melhor esforço, sem SLA ou garantia de prazo. Issues no GitHub costumam ser a forma mais rápida e ajudam a comunidade. Para assuntos privados, use o e-mail.

6. Privacidade e licença

O app não coleta dados. Leia a Política de Privacidade. O código é aberto sob licença MIT.
