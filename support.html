Support

Version 1.0 · Last updated: 20 November 2026

Need help with the AVIFnim Viewer? The app is free and open source (MIT); support is provided on a best effort, with no SLA.

Summary

Need help? Open a GitHub issue or email mayerdesigner@gmail.com. Include the app version, your OS, the file format, the steps and a screenshot if possible. AVIFnim Viewer is free and MIT; support is best effort, with no SLA. The app collects no telemetry and does not upload your files.

1. Support channels

  • GitHub Issues (preferred): github.com/everctba/AVIFnim-Viewer/issues — it becomes public and helps other people with the same problem.
  • Email: mayerdesigner@gmail.com — for matters that shouldn't be public (for example, sensitive data in the report).
  • Microsoft Store: for installation, update or account issues, use the Store's own support. The app is free.

2. Before asking for help

  • Check that you're on the latest version (GitHub Releases or Microsoft Store).
  • Try opening another file in the same format to see whether the problem is the file.
  • On Windows, restart the app after installing/updating.
  • On macOS, if the app doesn't open, see the section about the unverified developer warning.
  • On Linux, check your distro and the WebKitGTK version.

3. Frequently asked questions

Is AVIFnim Viewer free?

Yes. It's free, open source and licensed under MIT. There's no “premium” version of the viewer.

Which formats does it open?

AVIF (still and animated), WebP (still and animated), GIF, PPM/PNM (P1–P6), individual PNG and JPG, and numbered PNG/JPG sequences.

Which systems are supported?

Windows 10/11 x64 (NSIS installer or Microsoft Store), macOS 13+ (Intel and Apple Silicon) and Linux x64 (Ubuntu 24.04+ / Linux Mint, with WebKitGTK 4.1).

I can't open an image. What should I do?

Check whether the file opens in another program and whether the extension matches the content. If it persists, send the format, app version, system and step by step. If you can, attach a screenshot.

macOS warns that the developer can't be verified.

The app isn't signed/notarised by Apple yet. On first launch, right-click the app → Open → Open. If needed, use System Settings → Privacy & Security → Open Anyway.

Does it play animated AVIF on Linux?

Yes. When the system WebKitGTK can't decode AVIF, the app uses a native Rust decoder as fallback. If it fails, report your distro and the WebKitGTK version.

Is there a portable Windows version?

The portable version is planned (“coming soon”). Today the NSIS installer is the available format; it can be uninstalled from Windows apps.

Where are the settings?

In the app's data folder: %APPDATA%\com.avifnim.viewer on Windows, ~/Library/Application Support/com.avifnim.viewer on macOS and ~/.config/com.avifnim.viewer on Linux. Nothing is synced.

Are my files uploaded anywhere?

No. Everything is processed locally. The app has no telemetry, accounts or cloud. See the Privacy Policy.

How do I uninstall it?

On Windows, use Settings → Apps → Installed apps. On macOS, drag the app to the Trash. On Linux, remove it with the package manager (.deb). Local settings can be deleted manually.

How do I report a bug?

Open a GitHub issue or email with: app version, system, file format, steps to reproduce and, if possible, a screenshot. Don't send confidential files unless necessary.

4. Known issues

  • macOS: the app isn't signed/notarised yet; use “Open” in the context menu on first run.
  • Windows: the NSIS installer may trigger SmartScreen because it has no code signature; use “More info → Run anyway”. On the Microsoft Store, this warning doesn't appear.
  • Linux: AVIF depends on WebKitGTK 4.1; on older distros, the Rust fallback covers decoding.
  • Portable version: not published yet; use the installer.

5. Response time

The Viewer is maintained in best effort, with no SLA or deadline guarantee. GitHub issues are usually the fastest route and help the community. For private matters, use email.

6. Privacy and license

The app collects no data. Read the Privacy Policy. The code is open under MIT license.
